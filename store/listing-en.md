**Full description** (4000 max)

Start your coding journey with Yatri, your robot guide. CodeYatra teaches real programming in short, playful lessons, from your first logic puzzle to your first full-stack app.

🧭 8 LANGUAGE TRACKS, 40+ MODULES
• Logic & Blocks: think like a programmer with puzzles
• HTML: tags, lists, links, forms and page layout
• CSS: colours, box model, Flexbox and responsive design
• JavaScript: variables, arrays, objects and the DOM
• Python: from variables to dictionaries and problem solving
• React: components, state, lists, events and useEffect
• Node.js: modules, async/await, Express and JSON APIs
• Next.js: layouts, dynamic routes, server components and route handlers

📖 READ, THEN PRACTISE
Every module starts with a short reading card and a quick check. Then you practise for real:
• Fill-the-gap code with a live preview that updates as you type
• A real code editor that runs Python and JavaScript and checks your answer with tests
• Block puzzles where Yatri walks your program step by step

🔥 STAY ON TRACK
• Daily goal and streaks, with streak freezes for busy days
• Daily reminder at a time you choose
• XP, coins and outfits for Yatri
• Weekly league against other learners

🎓 SHOW WHAT YOU KNOW
Finish a track to earn a certificate you can share.

👤 MAKE IT YOURS
Add a profile photo, write a short bio and pick your main language.

📶 MADE FOR INDIA
Lightweight, works on budget phones, and most lessons work offline once loaded. Examples use trains, chai and cricket, not foreign menus.

Built for students from Class 8 to B.Tech, BCA and self-learners. Free to learn.
