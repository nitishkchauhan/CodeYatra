## 3. Curriculum gaps
- Only Python Foundations meets Lesson v2. HTML, CSS, JavaScript, React, SQL, DSA, CBSE, Placement and Logic are still v1 (one short card and about two exercises per module).
- Not in the app at all: C++, TypeScript, backend auth and testing, Docker, CI/CD, cloud, NumPy/pandas, statistics, ML, OS, networks, system design, Flutter.
- Module practice sets exist only for Python and Next.js.

## 4. Roadmap and navigation problems
- Roadmap "pan and zoom" is not used; a vertical map plus search and "My stop" is used instead (deliberate, for one-handed use on 360 dp phones).
- Home's journey shows one track at a time, not a path's modules across languages.

## 5. Technical risks
- No automated device (Android) UI tests; animations can't be checked in the hidden web preview.
- Local builds depend on one PC and WSL; EAS free quota resets 1 Nov.
- Content lives in TypeScript files (good for type checking and tests), so a content fix needs an app update.
- Many interface strings are still hard-coded in components; only part of the UI uses `useT()` (a Hindi version needs that finished).

## 6. Priorities (this round)
1. Next.js 16 track in Lesson v2 with practice, checkpoints and a project (mandatory core track).
2. Five roadmap stop states: not started, in progress, completed, assessment passed, mastery demonstrated.
3. Spaced repetition: a saved, simple review schedule for finished modules, with a "due today" queue.
4. Official further reading on lessons, with last-reviewed dates.
5. Home: one card for revision that is due.

Later rounds: SQL and DSA in Lesson v2 (Data Analyst and Placements), React and JavaScript, then TypeScript, backend, DevOps, AI and mobile.
